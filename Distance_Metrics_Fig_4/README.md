## Compute vector distances and inter-heterogeneity density plots

This project analyzes the BMI dataset by computing pairwise vector distances between histopathology image samples and generating inter-heterogeneity density plots to visualize relationships between tissue regions and BMI groups.

### File Descriptions

| File | Purpose |
|------|---------|
| `inter_heter_metrics.py` | **Main computation script.** Loads patient clinical data and histopathology vectors, computes pairwise cosine distances, and generates average-of-distance (AoD) metrics. Produces CSV files with distance metrics and PNG figures with distance matrices, boxplots, and density plots. |
| `plot_densities_ntbook.ipynb` | **Visualization notebook.** Reads the AoD CSV files generated by `inter_heter_metrics.py` and creates density comparison plots across tissue regions and BMI groups. |
| `constants.py` | Placeholder paths to the slide vectors (`VECTORS_ROOT`) and the clinical CSV (edit before running), plus region codes/names and BMI group mappings. Used by `inter_heter_metrics.py`. |
| `datahandler.py` | Utility functions: `get_vectors_dataframe()` reads HDF5 vector files; `get_bmi_category()` and `get_bmi_group()` classify BMI values. Used by `inter_heter_metrics.py`. |
| `utilities.py` | Plotting utilities and statistical functions (`mann_whitney_u_test()`, `make_multipartite_figures()`, etc.). Available for custom analyses. |
| `requirements.txt` | Pinned Python dependencies (numpy, pandas, scipy, h5py, matplotlib, seaborn). Use Python 3.12. |

The data is not stored in this repo. Set these paths in `constants.py`:

- `VECTORS_ROOT`: the `CANVOI_v1_1` folder created by unzipping `slide_vectors.zip` from the dataset (`.../VECTORS/Demographics_321/20x/CANVOI_v1_1`). The seven region files in `vector_data` (`ids` and `vectors` arrays) are found from there. The `TumorDense`, `TumorNotDense`, `StromaDense` and `StromaNotDense` files are the slide vectors of the high- and low-density subregions defined by [Tile_Clustering](../Tile_Clustering/).
- `patient_cohort_data`: clinical CSV (`/path/to/large_group.csv`) with columns `block_name` and `BMI`. The optional `-age`, `-er` and `-her2` filters also need `Age`, `ER` and `HER2` columns, which are not in the distributed CSV.

Output folders (`RESULTS_HET/`, `RESULTS_BY_DENSITY/`) are created by the script when you pass `-out`.

### Quick Start: Generate Data for the 3×2 BMI Comparison Plot

The `plot_densities_ntbook.ipynb` notebook displays a 3×2 grid comparing low and high BMI groups across six tissue region types. To generate only the data needed for this plot:

```bash
# Run from inside Distance_Metrics_Fig_4/
pip install -r requirements.txt

# Generate data for standard regions (RESULTS_HET)
python inter_heter_metrics.py -reg tumor -bmi low -out RESULTS_HET
python inter_heter_metrics.py -reg tumor -bmi high -out RESULTS_HET
python inter_heter_metrics.py -reg stroma -bmi low -out RESULTS_HET
python inter_heter_metrics.py -reg stroma -bmi high -out RESULTS_HET

# Generate data for dense/not-dense clusters (RESULTS_BY_DENSITY)
python inter_heter_metrics.py -reg TumorDense -bmi low -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg TumorDense -bmi high -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg TumorNotDense -bmi low -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg TumorNotDense -bmi high -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg StromaDense -bmi low -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg StromaDense -bmi high -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg StromaNotDense -bmi low -out RESULTS_BY_DENSITY
python inter_heter_metrics.py -reg StromaNotDense -bmi high -out RESULTS_BY_DENSITY
```

This generates 12 CSV files (4 in `RESULTS_HET`, 8 in `RESULTS_BY_DENSITY`) and corresponding PNG figures. The notebook reads the `aod` column from these CSVs. Set `ROOT_DATA_OG` and `ROOT_DATA_DIR` in its first cell if you used different output folders.

### Detailed Usage

For complete options and advanced filtering (age range, ER status, HER2 status):

```bash
python inter_heter_metrics.py -h
```

Example with additional filters:

```bash
python inter_heter_metrics.py -reg stroma -bmi high -age 25-50 -er pos -out RESULTS_HET
```

This creates `aod_stroma_bmi-high_age-25-50_erpos.csv` (AoD values per patient) and `fig_stroma_bmi-high_age-25-50_erpos.png` (visualizations).
